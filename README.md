## About Me

Undergraduate cybersecurity student, open-source maintainer, and cloud security enthusiast. I build secure cloud infrastructure, automate IAM guardrails, and audit decentralized applications — with a growing focus on the Stellar Soroban ecosystem.

- 🔐 **Cloud & Security:** GCP, AWS, IAM Policy Management, Cloud Security Auditing
- ⚙️ **DevOps & Automation:** Linux CLI, Advanced Bash Scripting, Local Command Automation
- 💻 **Languages:** Python, Rust, Bash, SQL, TypeScript
- ⛓️ **Web3 & Blockchain:** Stellar / Soroban Smart Contracts
- 🌱 Currently working toward the **Google Cloud Cybersecurity Certification**
- 🈴 Keeping a daily streak learning **Japanese**
